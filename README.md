# 纯粹直播 · Rust 掌机版

基于 [纯粹直播 PureLive](https://github.com/wzgrx/PureLive) 的非官方 Windows x64 掌机版，面向 ROG Xbox Ally X 和使用 Xbox 手柄的 Windows 掌机。界面使用 Rust 和 GPUI Kit，直播平台适配器来自上游 PureLive 5.6.5。

从 [Releases](https://github.com/soandsoprogrammer/PureLive-Xbox-Ally/releases) 下载 Rust 掌机版 Windows x64 ZIP，完整解压后运行 `purelive-gpui.exe`。

应用用法和构建说明见 [掌机版说明](gpui-prototype/README.md)。许可证为 [AGPL-3.0](LICENSE)，原项目与原生依赖的源码入口见 [第三方组件](THIRD_PARTY.md)。
